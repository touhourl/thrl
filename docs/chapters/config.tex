\subsection{Workers}

chunk\_size must be divisible by gru.seq\_len. With off\_policy = false, 
collection is paused while a policy update is prepared.  In off-policy mode collection could
continue (this gives you more speed), but chunks older than max\_policy\_staleness policy versions are discarded.

The frame\_interval\_ms and action\_repeat\_sleep\_ms values control speed of interaction.
episode\_cooldown\_ms adds a delay between episode to avoid atom bombs while do nothing. The
restart\_sleep\_ms is the worker-level delay before restarting a
failed environment. Not recommended to change other than frame\_interval\_ms.

\subsection{Observation}

grid\_w and grid\_h are the map resolution. Larger maps preserve more 
details but increase update memory and CNN work, and is approximately 
in proportion to $grid\_w \times grid\_h$. 

For schema 1, setting egocentric\_map = true changes spatial
projection from the fixed playfield to a player-centered region.  The width
and height of this region are decided by
egocentric\_map\_span\_x\_px and
egocentric\_map\_span\_y\_px.

\subsection{Reward scaling and the Lagrangian constraint}

The lagrangian table configures the death-rate constraint used by
MOPPO.  max\_death\_rate is the target upper bound,
dual\_lr is the dual-variable update rate,
dual\_min and dual\_max bound the multiplier, and
initial\_lambda is its initial value.
